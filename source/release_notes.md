# Release Notes

本文记录 AXERA Edge Computing Docs 的版本更新、适用范围和已知问题。这里的版本号表示文档版本，不等同于芯片 SDK、驱动、Pulsar2 或模型仓库的版本号；使用具体产品时，请以对应页面标注及官方发布包为准。


## 版本 v1.1.0

**发布日期：2026-09-06**

### 文档内容

- 新增 AX-Pipeline 内嵌 Web 控制台说明。
- 新增“智能编码”方案。
- 在文档页面接入 docs-assistant 前端客户端，直接AI机器人问答。

## 版本 v1.0.0

**发布日期：2026-08-02**

### 首次发布

- 建立 AXERA 边缘计算产品线的一站式文档体系，提供产品概览和按角色划分的阅读路径。
- 收录 AX8850 和 AX8910 的产品定位、核心规格及典型应用场景。
- 提供 CNN、Transformer、LLM 和 VLM 的性能数据与 Benchmark 环境检查方法。
- 提供官方开发板快速上手、接口说明、固件烧录和基础调试流程。
- 提供 SDK 获取、构建环境、交叉编译工具链、系统资源查询、CMM 配置和 NPU 基础操作说明。
- 收录智能视频与存储、智慧办公与交互、端云协同和双目深度等行业方案。
- 建立生态硬件、第三方解决方案和社区支持入口。
