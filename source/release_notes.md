# Release Notes

本文记录 AXERA Terminal Product Docs 的版本更新、适用范围和已知问题。这里的版本号表示文档版本，不等同于芯片 SDK、驱动、Pulsar2 或模型仓库的版本号；使用具体产品时，请以对应页面标注及官方发布包为准。


## 版本 v1.0.0

**发布日期：2026-08-05**

### 首次发布

- 建立 AXERA 终端计算产品线的一站式文档体系，提供产品概览、型号选型、模块使用和按角色划分的阅读路径。
- 收录 AX620、AX615、AX637 和 AX520 的产品定位、核心规格、使用说明及典型应用场景。
- 提供外设模块、多媒体模块、NPU模块、Sensor模块、内存泄漏等模块的debug定位检查方法。
- 提供图像调试、参数转换、调试工具使用等图像相关工具的使用方法。
- 提供官方开发板快速上手、接口说明、固件烧录和基础调试流程。
- 提供 SDK 获取、构建环境、交叉编译工具链、系统资源查询、CMM 配置和 NPU 基础操作说明。
- 收录IPC智能视频、快启、AOV和双目深度等行业方案。
